# Train_Cross
This coursework implements a controller for a railway level crossing where a
railway line intersects a public road. The system continuously monitors up to
three trains simultaneously, tracking each train's distance from the crossing
(0-10,000m range), current speed (0-56 m/s), and presence status. It also
monitors sensor health status. The primary safety requirement is that road
barriers must be down whenever any train is within its speed-dependent danger
distance (calculated using a non-linear formula: 800m base + speed²/2,
reflecting the physics principle that stopping distance increases with the
square of velocity, so a 50 m/s train requires 2,050m danger distance while a
20 m/s train needs only 1,000m), or whenever a sensor fault is detected
(fail-safe protection). The system repeatedly prompts the operator for sensor
status and train data, calculates the required barrier state using formally
verified safety logic, and displays comprehensive status information. This is
safety-critical because barrier failures can result in catastrophic high-speed
collisions between trains and road vehicles, causing multiple fatalities and
severe infrastructure damage, with no time for manual intervention once a train
enters the danger zone.
