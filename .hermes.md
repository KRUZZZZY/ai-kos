# AI-KOS v1.6

Hermes: you have full access to the AI-KOS knowledge database via MCP tools.
The knowledge/ directory is an Obsidian vault — use it for graph visualization.
Knowledge base is a separate repo at https://github.com/KRUZZZZY/ai-kos-knowledge.

## Quick reference
- Search knowledge: `ai_kos_search`
- Create article: `ai_kos_create`
- Ingest files: `ai_kos_ingest(filepath)`
- Compare for dupes: `ai_kos_compare(slug)`
- Run auto-linker: `ai_kos_link`
- Check health: `ai_kos_stats`
- Clean inbox: `ai_kos_clean`
- Research plan: `ai_kos_research_plan(question)`
- Persist research: `ai_kos_research_persist(question, findings, synthesis)`
- Run migrations: `ai_kos_migrate` (or `ai_kos_migrate --dry-run`)

## Durable pipeline
- ResearchPipeline: `pipeline = ResearchPipeline.create(question)`, then `pipeline.run(search_fn=...)`
- Survives crashes, retries failed steps, persists state to `knowledge/pipelines/{id}.json`
- Resume: `ResearchPipeline.load(path).resume()`

## Semantic search (optional)
- Install: `pip install sentence-transformers faiss-cpu`
- Build index: `ensure_semantic_index()`
- Hybrid search: `hybrid_search(query)` — combines TF-IDF + vector RRF

## TaskQueue
- SQLite-backed inbox processing: `q = TaskQueue(); q.scan_inbox(); q.process_all(handler)`
- Dead-letter isolation after max retries

## Bindings
- Config via `config.yaml` or `AI_KOS_*` env vars
- `kb_path()`, `inbox_path()`, `templates_path()` helpers with explicit override pattern

## Standard workflow
1. Drop files in inbox/
2. `ai_kos_ingest(filepath)` → extract text, detect type
3. Read + simplify content → `ai_kos_create(type, data)`
4. System auto-links (>=2 shared keywords), reports merge candidates
5. `ai_kos_clean` → archive source, move projects, reject binaries

## Session writeback
At end of significant sessions: review what was learned → create articles.
Follow the creation protocol in [[creation-protocol]].
Prioritize: process articles (skill backups) > base articles (concepts) > research notes.

## Knowledge base
- 71 articles, 7 types: base, process, plan, help, research-note, note, mission
- Auto-linking: >=2 shared keywords → [[wikilinks]]
- Merge detection: >80% overlap → flagged
- Search: TF-IDF full-text + optional vector semantic search
- Graph: Obsidian vault or D3.js (graph.html)
- Deep research: ResearchPipeline with durable execution
